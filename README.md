A one-line review of planet Earth written by an alien tourist: four stars for the oceans and kind hosts, minus goodwill for the small furry gods the locals serve — the ones who ignore them, knock things off tables, and demand food at 3am. Running `main.py` writes the review (171 characters, a single line of plain text) to `/output/entry.txt` for the make.fun "Alien Field Notes: The Two Day Earth Review" bounty.

## Run it

```sh
python3 main.py
```
